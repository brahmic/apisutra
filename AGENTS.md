# Инструкции для работы с ApiSutra

## Область действия

Этот репозиторий содержит самостоятельный пакет `brahmic/apisutra`: ядро SDK,
его тесты, примеры и документацию. Особенности конкретных внешних API относятся
к SDK провайдеров; в ядре остаются общие механизмы и контракты.

Перед работой выберите инструкции по задаче в [указателе правил](.agents/README.md).
Описание пакета и навигация по руководствам — в [документации](docs/README.md).
Внутренние аудиты, планы и решения для разработки — в [.workflow](.workflow/README.md).

## Обязательные правила кода

- PHP 8.4+, PSR-12, `declare(strict_types=1);` в PHP-файлах.
- Типизируйте параметры, возвращаемые значения и свойства.
- Используйте импорты `use` вместо полных имён классов в коде.
- Пишите комментарии в коде на русском языке.
- Сохраняйте возможность работы ядра без приложения Laravel; интеграционные
  возможности описывайте с их фактическими зависимостями.

## Рекомендации

Предпочитайте `readonly` для данных, которые не должны меняться после создания.
Используйте изменяемое состояние, когда оно требуется поведением объекта.
Сохраняйте структуру существующего модуля ядра; раскладка SDK провайдеров
применяется в области, указанной в [правилах провайдеров](.agents/providers.md).

## Проверка изменений

Команды выполняются из корня этого репозитория:

```bash
composer install
composer test
```

Для проверки отдельного теста: `vendor/bin/pest tests/Unit/Core/ValidatorTest.php`.
Тесты используют локальные зависимости пакета; приложение ihpoh и база данных
для них не нужны. При изменении поведения проверяйте затронутые сценарии.
Для правок только в документации проверяйте ссылки и соответствие описания API.
