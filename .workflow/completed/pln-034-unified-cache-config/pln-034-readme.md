## Задача

По поручению владельца собрать подключение и параметры кеша в единственном
ClientConfig::cacheConfig, сохранить исправления AS-6 и выпустить новую версию.
Основание — [ADR-005](../../adr/adr-005-unified-cache-config.md).
Разделение HTTP/auth и новые флаги отключения в объём не входят.

## Границы

Ключи, TTL существующих записей, identity, приоритеты HTTP overrides, auth locks,
rate-limit и metadata cache сохраняются. Переданные зависимости не клонируются.
Релиз v0.4.0-alpha.1 не переписывается. Миграция несовместимого API описывается явно.
