# Доказательства плана 034

baseline.json содержит принятый commit, дерево src, PHP и SHA-256 исходников.
Каждая проверка записана тройкой `<метка>.json/.stdout/.stderr`: команда и код выхода,
полные нормализованные логи. Нормализация удаляет только цвета терминала и конечные
пробелы/пустые строки. Неудачные первые проверки сохранены вместе с объяснением в
[отчёте](../implementation.md). Финальные результаты имеют отдельные метки.

Повтор: из корня репозитория `python3 <путь>/run-check.py <новая-метка> <команда>`.
Установка зависимостей: `composer install --no-interaction --prefer-dist --no-progress`.
