## Редакторские решения и границы

Дерево расширено со 135 до 138 страниц по трём самостоятельным темам, перечисленным
в [structure](structure.md). `moves.md` собран при приёмке; до переноса использовалась
машинная карта разделов. Порядок фиксации отличается от буквального пункта плана,
покрытие проверяется отдельно по каждому прежнему заголовку.

Проверки не доказывают все утверждения естественного языка и не выполняют каждый
контекстный фрагмент справочника. Внешние веб-ссылки и реальные API не проверялись.
Их граница явно описана в [сопровождении документации](../../../development/documentation.md).
Полнота и отсутствие конкурирующих спецификаций проверялись редакционно по темам;
число файлов/ссылок не используется как самостоятельное доказательство этого.

План полностью перенесён в completed. В current осталась короткая страница перехода,
чтобы сохранить ссылки и SHA-256 двух исходных документов завершённого 028; она
не содержит статуса или копии плана. Единственный полный план находится здесь.
