# Исторический архив

Здесь сохранены старые материалы, в том числе перенесённые из `.temp/`.
Они могут быть ошибочными или устаревшими и не являются источником истины,
действующей спецификацией или инструкциями для текущей работы.

Архив не участвует в обычном рабочем процессе. Обращайтесь к нему только
для целевого расследования проблемы или изучения прошлого; сведения используйте
как дополнительный контекст и перепроверяйте по текущему состоянию проекта.

Полные [правила использования архива](../README.md#исторический-архив).
