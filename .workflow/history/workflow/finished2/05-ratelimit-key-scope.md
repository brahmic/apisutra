# План 05: расширить ключ rate limit (P1)

## Проблема
`src/Pipeline/Transport/RateLimitApplier.php` формирует ключ только по `baseUrl`, из‑за чего лимиты смешиваются между разными клиентами/пользователями.

## Рекомендованное решение
- Включить в ключ: `baseUrl` + `clientId` (или auth identity) + опционально `method/path`.
- Разрешить override ключа через `RateLimitConfig`/`RequestOptions`.
- Документировать default‑стратегию формирования ключа.

## Нюансы
- Не включать чувствительные данные (только стабильные идентификаторы).
- Ключ должен быть стабильным между процессами при использовании cache.
