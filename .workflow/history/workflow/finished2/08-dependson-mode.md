# План 08: использовать mode в DependsOnExecutor (P2)

## Проблема
`src/Execution/DependsOnExecutor.php` принимает `mode`, но игнорирует его и всегда работает в sequential‑режиме.

## Рекомендованное решение
- Либо удалить параметр из публичного API и всех вызовов.
- Либо реализовать поддержку mode (Sequential/Parallel) через стратегию выполнения.

## Нюансы
- Параллельность должна сохранять порядок агрегации результатов.
- Для совместимости предпочтительнее реализация, а не удаление.
