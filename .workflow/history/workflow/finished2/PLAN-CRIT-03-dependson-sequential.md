# План: сделать DependsOn последовательным

## Цель
Гарантировать, что зависимости выполняются строго последовательно.

## Контекст
Файл: `packages/brahmic/apisutra/src/Execution/DependsOnExecutor.php`  
Проблема: `ExecutionMode::Parallel` может быть передан и применён.

## Шаги
1) В `DependsOnExecutor::execute()` принудительно использовать `ExecutionMode::Sequential`.
2) Игнорировать входящий `$mode` (или заменить на `Sequential` внутри).
3) Обновить документацию (если требуется): зависимости выполняются последовательно.

## Критерии приёмки
- Зависимости никогда не исполняются параллельно.
- Поведение `FailAll` сохраняется (остановка на первом failed).

## Риски
- Потеря производительности в сценариях, где параллельность допустима.  
  Решение: оставить это поведение только для DependsOn, а не для Composite/Batch.
