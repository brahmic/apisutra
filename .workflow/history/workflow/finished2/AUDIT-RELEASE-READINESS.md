## Важные риски перед релизом
1. **`sendAsync()` при пагинации фактически синхронный**  
   В `AbstractClient::sendAsync()` для пагинации выполняется `requestResolver->resolve()` синхронно, а результат упаковывается в `Promise`.  
   Файл: `src/Core/AbstractClient.php`.  
   Риск: блокировка для больших пагинаций и несоответствие ожиданиям async API.

2. **Отсутствие валидации `ClientConfig`**  
   Закрыто: добавлена базовая валидация `baseUrl`, таймаутов, задержки, попыток и idempotencyHeader.  
   Файл: `src/Config/ClientConfig.php`.

3. **Исключения на ранних этапах пайплайна не оборачиваются в `ExecutionResult`**  
   Закрыто: `Pipeline::execute()` оборачивает весь пайплайн в try/catch и учитывает `throwOnErrors`.  
   Файл: `src/Pipeline/Pipeline.php`.

4. **Пагинатор не имеет «жёсткого» лимита страниц по умолчанию**  
   Закрыто: добавлен `PaginationConfig.maxPages` и guard по количеству страниц.  
   Файл: `src/Pagination/Paginator.php`.

5. **Релизная конфигурация пакета**  
   В `composer.json` стоит `minimum-stability: dev`. Для публичного релиза желательно фиксировать стабильный профиль.  
   Файл: `composer.json`.

## Качество архитектуры (сильные стороны)
- Чёткая модульная структура: `Core`, `Pipeline`, `Execution`, `Result`, `Pagination`, `Extensions`, `Files`.
- Широкое использование контрактов и VO, строгая типизация.
- Централизованный пайплайн с понятными стадиями и расширяемыми хуками.
- Модуль расширений с регистрами и расширяемыми точками (Hooks, ResponseHandlers, Casts).
- Хорошая база unit‑тестов по ключевым подсистемам.

## Покрытие бизнес‑сценариев (тесты)
Ниже — ключевые пробелы по бизнес‑сценариям и краевым случаям.

### Discovery / Registry / Resolver
- Нет тестов на fallback‑конвенции и множественные namespace для auto‑discovery.
- Нет теста инвалидации кеша discovery при изменении composer checksum.
- Нет тестов на нормализацию namespace и очистку `resolved` кеша в registry.
- Нет теста на отсутствие клиента в registry.

### Pipeline / Execution
- Нет тестов порядка стадий при ошибках, `skipValidation/skipComposite`, `throwOnErrors`.
- Нет тестов исключений в хуках и `EarlyReturnException` на разных стадиях.
- Нет тестов на пустые коллекции, `stopOnFailure` в pool с concurrency > 1.

### Retry / Rate limiting
- Нет тестов для разных `BackoffStrategy` в реальных сценариях.
- Нет тестов `Retry-After` (секунды vs дата) и retry при 429 без `Retry-After`.
- Нет тестов сочетания refresh auth + retry.

### Results / Errors
- Нет полного покрытия маппинга HTTP статусов в ошибки/исключения.
- Нет тестов для `PARTIAL` статуса и смешанных коллекций результатов.
- Нет тестов для ошибок без JSON body.

### Pagination
- Нет тестов на одинаковый `nextCursor` (защита от циклов).
- Нет тестов `range()` для некорректных параметров и `pages(0)`.
- Нет тестов для противоречивой меты (`total=0` + `hasMore=true`).

### Files
- Нет тестов на несуществующий файл в `fromPath()` и разные типы stream.
- Нет тестов на `Binary/Base64` upload и множественные файлы.
- Нет тестов streaming‑сохранения больших файлов.

### Асинхронность и интеграция
- Нет тестов для `sendAsync()` с ошибками/rejection.
- Нет интеграционного теста полного flow (discovery → pipeline → execution → result).
- Минимальное покрытие Laravel‑интеграции (`SdkServiceProvider`/DI).

## Документация и консистентность
1. **`RequestOptionsProviderInterface` отсутствует в глоссарии**  
   В коде используется, в `docs/` упоминаний нет.  
2. **`PaginationConfig` vs `PaginationRule`**  
   В коде активно используется `PaginationConfig`, в глоссарии описан только `PaginationRule`.  
3. **Нет пошагового туториала по созданию первого провайдера**  
   Есть примеры и архитектурные заметки, но нет «от нуля до первого запроса».
4. **Дубли и «разъезды» между глоссарием и `.temp/release_docs`**  
   Нужна единая «истина» и перекрёстные ссылки.

## Готовность к первому провайдеру
**Частично готово**: архитектура расширяемая, контракты и пайплайн зрелые.  
**Не хватает**: пошагового руководства, тестов интеграции и формализованных edge‑case сценариев (async/pagination/errors/files).
