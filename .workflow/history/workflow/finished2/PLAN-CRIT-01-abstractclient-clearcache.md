# План: устранить дублирование clearCache в AbstractClient

## Цель
Убрать дублирование метода `clearCache()` и сохранить корректное поведение очистки кеша.

## Контекст
Файл: `packages/brahmic/apisutra/src/AbstractClient.php`  
Проблема: в классе определены **две** одинаковые сигнатуры `clearCache()`, что делает класс невалидным.

## Шаги
1) Выбрать единственную реализацию `clearCache()`:
   - использовать `cacheConfig?->store ?? cache`, вызывать `clear()` при наличии.
2) Удалить дубликат, убедиться что сигнатура остаётся неизменной.
3) Проверить вызовы:
   - `AbstractRequest::clearCache()` → `clearCacheForRequest()`.
   - `clearCache()` используется только для полного очищения.

## Критерии приёмки
- Класс успешно загружается, нет фатальных ошибок.
- `clearCache()` очищает store при наличии.
- Поведение `clearCacheForRequest()` не меняется.

## Риски
- Потеря `method_exists` проверки для нестандартного store.  
  Решение: оставить безопасную проверку или использовать контракт `CacheInterface`.
