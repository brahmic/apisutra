# План 07: валидация RetryConfig (P2)

## Проблема
`src/Config/RetryConfig.php` принимает некорректные значения без проверки.

## Рекомендованное решение
- Ввести валидацию в конструктор: `attempts > 0`, `baseDelay >= 0`, `maxDelay >= baseDelay`.
- При ошибке выбрасывать `ConfigurationException` (или доменный аналог).

## Нюансы
- `maxDelay` может быть `null`.
- Дефолтные значения должны проходить без ошибок.
