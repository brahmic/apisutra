# Передать задачу ИИ-агенту

Это карточка задания для агента, который использует ApiSutra: создаёт SDK,
добавляет операцию или работает с DTO. Все контракты и критерии общие с человеком.

## Контекст задания

Передайте агенту:

- репозиторий и версию SDK/ApiSutra, ограничения PHP и окружения;
- выбранную задачу и границу готового результата;
- документацию внешнего API и обезличенные фикстуры;
- существующие конфигурацию, клиент, правила DTO и принятые примеры операций;
- доступные команды проверки, ограничения сети и известные неизвестные условия.

Credentials не нужны для работы с fake. Разрешение на настоящие запросы, их
стоимость и sandbox задаются отдельно владельцем интеграции.

## Выбрать общий маршрут

| Задание | Инструкция и критерии |
| --- | --- |
| Создать SDK с нуля | [Создание SDK](create-sdk.md) |
| Дополнить SDK | [Добавление операции](add-operation.md) |
| Описать данные | [DTO](describe-dto.md) |
| Подключить SDK к приложению | [Использование](use-sdk.md) |
| Найти причину сбоя | [Диагностика](diagnose.md) |

Агент выполняет порядок выбранного маршрута и обращается к его ссылкам в справочник.
У этой карточки нет отдельной спецификации, набора приоритетов или упрощённых критериев.

## Передать результат

Укажите изменённые файлы и публичный вызов, команды и фактические результаты
проверок, покрытые сценарии, ограничения и оставшиеся вопросы. Различайте проверенный
факт API, вывод по коду и предположение. Не объявляйте неподтверждённое поведение
провайдера гарантией SDK.

[Учебный SDK](../example/sdk/README.md) показывает минимальный состав результата.
Для изменения самой ApiSutra нужны инструкции checkout из
[CONTRIBUTING](https://github.com/brahmic/apisutra/blob/master/CONTRIBUTING.md).
