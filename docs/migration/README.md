# Миграция версий

Выберите изменения между установленной и целевой версией. Здесь перечисляются
действия пользователя; текущие полные контракты находятся в справочнике.

- [v0.2.0-alpha.1](v0.2.0-alpha.1.md) — транспорт, форматы ответа и дедлайн.
- [v0.3.0-alpha.1](v0.3.0-alpha.1.md) — await, метаданные и внешние правила DTO.
- [v0.4.0-alpha.1](v0.4.0-alpha.1.md) — разделение cacheStore и параметров кеша.
- [История изменений](../../CHANEGLOG.md) — последовательность изменений пакета.

Точки входа в документацию —
[по пользовательским задачам](../start/README.md); изменение пакета описано в
[CONTRIBUTING репозитория](https://github.com/brahmic/apisutra/blob/master/CONTRIBUTING.md).
Она не меняет runtime API.
